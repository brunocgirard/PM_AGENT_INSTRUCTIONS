# Responsibility matrix notation variants

## RACI
- **R** — Responsible: does the work
- **A** — Accountable: owns the outcome; final decision authority
- **C** — Consulted: provides input before or during the work
- **I** — Informed: notified after decisions or completion

## RASCI / RASIC
- **R** — Responsible
- **A** — Accountable
- **S** — Support: assists the Responsible party; shares workload
- **C** — Consulted
- **I** — Informed

## DACI
- **D** — Driver: leads the effort and keeps it moving
- **A** — Approver: makes the final call
- **C** — Contributor: provides input or does portions of the work
- **I** — Informed

## CAIRO / RACIO
- **C** — Consulted
- **A** — Accountable
- **I** — Informed
- **R** — Responsible
- **O** — Out-of-loop / Omitted: explicitly excluded from this activity
